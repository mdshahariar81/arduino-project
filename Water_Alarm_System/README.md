# Water Alarm System 💧

Arduino-based water alarm project.

## Components
- Arduino UNO
- Water Sensor
- LED
- Resistor
- Buzzer
- Jumper Wires

## Connections

### Water Sensor
- S → A0
- + → 5V
- G → GND

### LED
- Long leg → Pin 10 (through resistor)
- Short leg → GND

### Buzzer
- + → Pin 8
- - → GND

## Function
When water is detected:
- LED turns ON
- Buzzer starts beeping
